The Entity System

A taxonomy for agents that build agents. What an entity is, which family it belongs to, where it sits, and the tests that keep the corpus from quietly rotting.

01 — Definition

An entity is a file that changes behavior at the moment of use.

Not every useful paragraph is an entity. To count, a thing must satisfy all five conditions below. Anything missing one is a draft, not an entity.

01

Identity

A unique lowercase kebab-case name that matches its directory.

02

Routing contract

A description that decides when it is invoked. The most consequential line in the file.

03

Body

A procedure, a lens, or a procedure with examples. Something that does work.

04

Home

Exactly one scope: vault source plus its install target. Global or project, never both.

05

Registry line

One authoritative listing. An unlisted entity is invisible to the next audit.

02 — Principles

Three laws that decide what survives.

Law 1

Behavior delta. An entity earns its existence only by changing behavior at the moment of use. If behavior(with) == behavior(without), it is decoration.

Law 2

Routing contract. Expectations embedded in the description shape the behavior it produces. A vague description does not merely route poorly; it licenses vague work.

Law 3

Drift. Statues crumble silently. Nothing fails loudly when a registry goes stale or a technology ships a new version. The corpus keeps answering from an old map.

05 — Distinctions

The three boundaries that cause the most confusion.

Doctrine · Steward · Forge

Separate them by their main verb. This is a five-second test, not a philosophy seminar.

FamilyVerbInputOutput
Doctrinejudgea situation to evaluatejudgment
Stewarddecidea request for an entitya decision record
Forgeproducea settled decisionan artifact of a declared shape

A doctrine with an intake flow has become a steward. A steward that builds has stolen a forge's job. A forge that decides whether to exist is a scout.

Stale · Drifted

Stale

Time passed. The snapshot date is older than the threshold. The facts may still be right.

Drifted

The world moved. The declared version no longer matches upstream. The entity is confidently wrong.

Test staleness with a date. Test drift with a probe — a declared, re-runnable, read-only command that returns the current upstream version.

The producer rule

A producer may produce corpus entities that sit below it. It may never produce producers or governance.

ProducesExampleLegal?
a corpus entity, below itnerd-forge → *-nerd (L2 → L5)yes
a producer, same layerforge-forge (L2 → L2)no self-referential
governance, above itsteward-forge (L2 → L1)no production must not manufacture deciders
encoded judgmentdoctrine-forge (L2 → L4)no judgment in a producer's coat
a corpus entity, layer-legalgenie-forge (L2 → L5)yes if ripeness passes

Layer-legality is necessary, not sufficient. A layer-legal producer still needs ≥2 instances or named candidates, an explicit procedure, and observable quality variance.

06 — Recursion

Every family has a top. Climbing past it adds cost, not judgment.

prompt ─┐
skill ──┼─→ forge ─→ forge-nerd (terminal)
nerd ───┘              │
                       └─→ registry (terminal)

request ─→ steward (terminal)
genie ───→ genie-doctrine (terminal)
doctrine ─→ nothing above (a lens on a lens adds nothing)
scout ────→ nothing above (detection is already the top)

Forbidden by construction: forge-forge, steward-steward, doctrine-doctrine, nerd-forge-nerd-nerd, scout-forge.

If you feel the need to climb again, the level below is under-specified. Fix the spec.

07 — Health

Eight states. The audit names them so the steward can act.

zombie

Fails to load — bad YAML, missing description, name ≠ directory. Silently absent. Fix first.

ghost

Something references an entity that does not exist. A claim about existence that is false.

duplicate

Two entities with ≥85% description overlap. Both route unreliably. Merge or sharpen.

orphan

Exists but no registry or catalog lists it. Invisible to the next audit.

hollow

No procedure, no references, no examples. Costs context, returns nothing.

stale

Dated grounding past the threshold. An explicit Last verified: wins; fenced examples and audit-history tables are records, not grounding. Old, but possibly still true.

statue

Never invoked. Diagnose the trigger before deleting — the description is usually the fault.

drift

Upstream moved. Loadable, internally consistent, and confidently wrong.

08 — Terms

Normative definitions. When a word is capitalized, this is the authority.

Entity
A file-backed, discoverable unit that changes agent behavior when routed to. Requires identity, routing contract, body, home, and registry line.
Corpus
The complete set of entities plus their registries and catalogs. Has health, not just content.
Family
A named class sharing an anatomy, a role, and a registry of record.
Role
A family's function in the organization chart: governance, production, detection, knowledge, audit, corpus.
Registry of record
The single file that authoritatively lists a family's members and its spec. Two registries for one family is a duplicate at the spec level.
Scope
Where an entity is loaded: vault source, global, or project. Part of its identity.
Echelon
The prompt → skill → agent level of a request. Orthogonal to family.
Doctrine
An entity whose only output is judgment. No output shape, read by others, terminal, prescriptive.
Steward
An entity that receives requests, decides whether and how many entities are needed, routes production, and keeps the portfolio coherent.
Forge
A production entity: creates artifacts to a repeatable spec. Must declare an output shape and ship ≥1 canonical example.
Nerd
An expert persona for exactly one technology, grounded in a priority chain. Answers; does not produce artifacts.
Scout
A detection entity that flags opportunities. Does not build; its independence is the point.
Genie
A family that goes meta into software change artifacts — fixes, changelogs, PRs, issues, postmortems, design docs, tests, git history — to extract transferable lessons.
Behavior delta
The difference in agent behavior with the entity loaded versus without. The only valid justification for existence.
Routing contract
The description field. Determines invocation, and therefore whether the entity ever comes alive.
Gate
A binary pass/fail check: routable, different, bounded, registered. One failure blocks the entity.
Terminal climb
The maximum meta level a family may reach. Above it, recursion adds cost without judgment.
Intake card
The steward's decision record: restated request, expected delta, verdict, decomposition, org placement, producer, gates, next action.
Decomposition
Splitting one request into the minimum set of entities, one routing boundary each.
Probe
A declared, re-runnable, read-only command that returns the current upstream version. The test for drift.
Statue
An entity with no evidence of ever being invoked. Addressed by fixing the trigger, not the body.
